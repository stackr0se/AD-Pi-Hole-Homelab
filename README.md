# AD-Pi-Hole-Homelab

A virtualized mini company network built on a repurposed HP ProDesk 600 G1
(8GB RAM) running Proxmox VE.

## Environment
- Hardware: HP ProDesk 600 G1 Tower, 8GB DDR3
- Hypervisor: Proxmox VE
- Network: Quantum Fiber Modem/Router, managed from personal laptop Thinkpad T490 
- Personal home lab (not a production environment)
